# Upstream and maintenance

This repository is a maintained fork of `NicosNicolaou16/PitchKit`.

- Upstream baseline: PitchKit `1.0.1`
- Upstream baseline commit: `26a7909601bb33b08623b32605a6f731a3704cdd`
- Maintained integration branch: `modern-pitch-tuner`
- Fork version: `1.1.0-modern`
- Primary consumer: `Maf-Dy/modern-pitch-tuner`

The Modern Pitch Tuner application pins an exact commit from this fork. The app must not carry an independently edited copy of the PitchKit source.

Upstream changes are reviewed explicitly and selectively merged or cherry-picked. We do not automatically replace this fork with a newer upstream release because the fork changes processing modes, lifecycle behavior, DSP performance, public chord diagnostics, and neural chord recognition.

Apache-2.0 licensing and upstream copyright/attribution are retained. Modified files are tracked by Git history and this changelog.
